## Estados

| Estado | Significado |
| --- | --- |
| `não testada` | Ainda não foi executada por interface. |
| `em teste` | Execução e coleta de evidências em andamento. |
| `aprovada` | Fluxo, variações e resultado esperado foram confirmados. |
| `falhou` | Há defeito reproduzível; registrar causa e impacto. |
| `bloqueada` | Falta credencial, configuração, dado ou autorização externa. |
| `corrigida — reteste pendente` | Código alterado; ainda não revalidado. |
| `fora do escopo` | Funcionalidade conscientemente adiada por decisão de produto. |

## Regras de evidência

- Registrar rota, papel, dados de entrada, resultado e data.
- Não enviar mensagens reais, publicar ativos Meta, importar/exportar dados ou gastar crédito sem uma autorização já existente para a jornada específica.
- Exercitar tela estreita, tablet e desktop em toda jornada com interface.
- Não confundir teste de interface com confirmação de uma integração externa.
