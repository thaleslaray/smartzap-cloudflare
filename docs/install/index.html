Antes do deploy

Crie as chaves sem enviá-las para ninguém.

Esta página funciona antes de o seu SmartZap existir. A senha e a chave do cofre são geradas somente neste navegador. Não usamos servidor, analytics, cookies ou armazenamento local.

1. Defina a senha administrativa

Você usará esta senha para entrar no SmartZap. Se preferir, gere uma sugestão forte e salve-a no seu gerenciador de senhas.

  • 12 caracteres ou mais
  • uma letra maiúscula
  • uma letra minúscula
  • um número
  • um símbolo

2. Salve a recuperação

Os valores abaixo não poderão ser recuperados pelo SmartZap.

SMARTZAP_VAULT_KEY
MASTER_PASSWORD

3. Confira a conta antes de publicar

O botão só será liberado depois destas confirmações. Elas evitam cobrança inesperada, colisão com produção e falha silenciosa do clone.

Deploy to Cloudflare

Baixe a recuperação e conclua as cinco confirmações para liberar o deploy.
