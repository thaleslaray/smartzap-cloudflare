Instalação segura na sua Cloudflare
Código próprio recomendado

Escolha o fork ou uma instalação rápida.

O fork deixa código e atualizações sob seu controle. A rota OAuth permanece disponível para uma versão fixa, sem manutenção contínua.

  1. 1

    Produção: crie seu fork

    Seu GitHub recebe o código e a Cloudflare publica somente os pushes que você autorizar.

  2. 2

    Avaliação: use OAuth

    O provisionador instala uma versão fixa sem Git, mas não inclui atualizações.

  3. 3

    Conclua o /setup

    Nos dois modelos, valide infraestrutura, Meta, webhook, templates e mensagem real.

Comparar formas de instalação ↗

Nenhuma modalidade promete manutenção gratuita ou atualização automática. A senha e a chave do cofre são criadas no navegador.
