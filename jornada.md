# Jornadas do usuário — SmartZap

Este é o catálogo canônico e vivo das jornadas do produto. Ele descreve o que precisa existir e ser testado. Resultados detalhados de cada rodada pertencem a `Auditoria.md`.

Última consolidação: 05/08/2026
Histórico importado de: `docs/auditoria-jornadas.md`

## Regras de manutenção

- Toda nova função, rota, integração, estado ou variação deve entrar aqui na mesma alteração de código.
- Toda lacuna descoberta deve ser adicionada imediatamente como `não testada`.
- Uma jornada só pode ficar `aprovada` quando houver evidência compatível registrada em `Auditoria.md` ou no histórico legado.
- Alterações funcionais reabrem as jornadas afetadas como `corrigida — reteste pendente` até novo teste.
- Os IDs são permanentes. Jornadas removidas ficam `descontinuada`; não reutilizar o ID.
